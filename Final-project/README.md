# Uganda Vehicle Maintenance Guide

A responsive WDD231 individual website project built with semantic HTML, custom CSS, and vanilla JavaScript ES modules.

## Pages
- `index.html` — landing page
- `maintenance.html` — maintenance library with 18 JSON-driven items, search, category filter, favourites, and a details modal
- `contact.html` — accessible service request form
- `form-action.html` — displays submitted form values
- `attributions.html` — project source attributions

## Run locally
Use VS Code Live Server or another local web server. Do not open `maintenance.html` directly with a `file://` URL because browsers usually block Fetch API requests to local JSON files.

## Before submission
1. Replace every `VIDEO-LINK-ADD-HERE` footer URL with the public URL of your 3–5 minute project demonstration video.
2. Check the content, metadata, accessibility, and responsive layout against the course rubric.
3. Run the website with Live Server and test all controls, especially JSON fetching, favourites after refresh, modal keyboard interaction, and form submission.
4. Validate HTML/CSS and run Lighthouse audits.
5. Commit the complete `vehicle-maintenance` folder into your `wdd231` GitHub repository.
6. Update the Final link on your Week 1 page to point to `vehicle-maintenance/index.html`.

## Important note
The site is an educational guide, not professional mechanical advice. Maintenance intervals vary by vehicle; consult the manufacturer's manual and a qualified mechanic.
