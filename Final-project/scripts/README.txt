JavaScript modules included:
- main.js: initializes common navigation and footer year.
- site.js: reusable navigation and year functions.
- maintenance.js: Fetch API, try/catch, JSON parsing, filters, card rendering and event handling.
- modal.js: accessible native dialog interaction and detail display.
- storage.js: localStorage functions for favourites and the maintenance-tip preference.
- contact.js: contact form preference handling.
- form-action.js: safely displays submitted values using textContent.
