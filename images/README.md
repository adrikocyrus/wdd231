Final Project

Automobile Mechanic Learning Hub

The final project is a three-page educational website designed to help users learn about automobile mechanics.

The website includes:

Engine systems information
Workshop tools and equipment
Tool descriptions and safety information
Interactive JavaScript features
Favorite tools using Local Storage
Responsive design for different screen sizes
Accessible and user-friendly navigation
